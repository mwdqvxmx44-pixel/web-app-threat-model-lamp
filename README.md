# Secure Web Application Architecture & STRIDE Threat Model

## Overview
A comprehensive security assessment and resilient enterprise architecture design evaluating Cross-Site Scripting (XSS) vulnerabilities across a LAMP stack (Red Hat Enterprise Linux, Apache, MySQL, PHP).

## Key Components
* **STRIDE Threat Modeling:** Identified attack vectors, trust boundaries, and mitigation strategies across the web application lifecycle.
* **Vulnerability Assessment:** Analyzed CVSS metrics for vulnerabilities across the base operating system, web server, database, and application runtime.
* **Resilient Architecture:** Modeled a multi-tier infrastructure featuring redundant security zones, firewalls, load balancing, and database replication to eliminate single points of failure (SPOFs).
* **OWASP ASVS 4.0 Controls:** Implemented compensating security controls for data protection and transaction security.

## Technologies & Frameworks
* **Frameworks & Standards:** OWASP ASVS 4.0, STRIDE, CVSS v3
* **Stack:** Red Hat Enterprise Linux (RHEL), Apache, MySQL, PHP
